eBay-API (Bestellungen direkt holen)

Statt Adressen von Hand zu kopieren, liest SendPilot die offenen Verkäufe direkt über die eBay Sell Fulfillment API. Einmal einrichten, danach läuft es ~18 Monate ohne erneutes Einloggen.

–
Einrichtung (einmalig, ca. 5 Minuten)
  1. developer.ebay.com/my/keys → Produktions-Keyset anlegen. App ID = Client-ID, Cert ID = Client-Secret.
  2. Bei „User Tokens“ auf Add eBay Redirect URL. Den RuName-Wert übernehmen.
  3. Als Auth accepted URL exakt diese Adresse eintragen (eBay erlaubt kein http/localhost): –
  4. OAuth Enabled ankreuzen, speichern. Werte unten eintragen und „Verbinden“ klicken.
  5. Passende Scopes im Keyset freischalten: sell.fulfillment.readonly
